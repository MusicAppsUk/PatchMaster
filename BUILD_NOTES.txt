PatchMaster v21.17 — Stable Catalogue Recovery
15 Sep 2026

ROOT CAUSE FOUND
The v21.14-v21.16 search branch generated a catalogue request storm: automatic search fired after 1.4 seconds while typing, and each search could make multiple Apple requests plus fetch→JSONP retries and MusicBrainz calls. Apple documents an approximate 20 calls/minute limit; MusicBrainz requires no more than one call/second. This could rate-limit the app until it appeared unable to find any songs.

FIX
- Rebuilt from v21.15 research-recovery baseline, not v21.16.
- Removed automatic network search while typing.
- Search happens only on Enter or Search now.
- Exactly one Apple JSONP catalogue request per explicit search.
- MusicBrainz is a single fallback only if Apple yields no usable match.
- 24-hour local catalogue-result cache prevents repeat requests for the same query.
- Exact title dominates ranking; bare artist matching remains supported.
- Supports title by artist, title - artist, title — artist, and title, artist.
- Keeps verified local research packets as offline resilience.
- Research pipeline retains v21.15 Wikipedia-optional repair.
- Yamaha MIDI transport is untouched from v21.15.
